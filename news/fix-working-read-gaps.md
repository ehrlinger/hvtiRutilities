* A draft read of a declared dataset that has never been registered no longer writes a parquet cache and an unversioned `manifest.yaml` entry. That entry broke on the next rebuild, so `verify_manifest()` failed and every draft stopped until someone registered. The read is now served from the working file, uncached, as a working read, so `refresh = TRUE` on it now stops: there is no cache to refresh. It also reads the source in full on every call until the dataset is registered.
* `declare_data()` writes the empty `manifest.yaml` even when `_study.yml` already names the file, so a study declared before 1.5.12 gets one. Declaring the same file again with a `key` records it when none was declared, and stops when it differs from the declared key instead of ignoring it.
* `vignette("registered-datasets")` describes the working-read gate as it is: draft or final, in any stage folder, not the datasets and descriptive folders only.
