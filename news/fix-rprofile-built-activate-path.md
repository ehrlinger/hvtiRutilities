* `study_setup()` accepts a study's own `.Rprofile` that activates renv through a built path, such as `source(file.path(root, "renv", "activate.R"))`. It had required the literal `source("renv/activate.R")`, so `adopt = TRUE` stopped on studies whose path-independent `.Rprofile` was written by hand, reporting a partial renv environment with `.Rprofile` missing or invalid. A `.Rprofile` that never names `activate.R`, the half-finished `renv::init()` the check guards against, is still refused, and a commented-out line no longer counts.
