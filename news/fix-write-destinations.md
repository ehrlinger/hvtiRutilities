* Breaking: no exported function writes into the working directory by default any more, as the CRAN Cookbook's code chapter asks.
  * `update_manifest(file)` now defaults to `manifest_path = NULL`, which means the manifest at the root of the study that contains the working directory, the same file the no-argument form and `verify_manifest()` use. Outside a study it stops and asks for `manifest_path`, instead of writing `./manifest.yaml`. Inside a study it no longer leaves a stray `manifest.yaml` in a subfolder, such as a job's folder while Quarto renders it.
  * `study_setup()` with no `root` re-runs setup on the study that contains the working directory, as before. Outside a study it now stops and writes nothing, instead of creating a study in the working directory. To set up the current folder, call `study_setup(root = ".", adopt = TRUE, ...)`.
  * The writers that find their study by walking up to its `_study.yml` are unchanged, and outside a study they still stop and write nothing. `declare_data()` and `register_data()` now spell their `root` default as `study_root()` rather than `getwd()`, and `add_abbreviation()` and `study_update_identity()` their `start` default; each resolves to the same study as before. Their help pages, and those of `cache_fit()`, `study_declare()`, `study_checkpoint()`, `study_close()` and `study_reopen()`, now say so.
