* New `source_changed()` says whether a registered dataset's source has been rebuilt since it was registered, without reading any data. It compares the source's SHA-256 with the registered one every time, so it also catches a same-size replacement that kept the recorded modification time, which `read_built()`'s stat shortcut does not. It exists so a report can say a newer build is waiting before it reads the data (hvtiRtemplates' top box).
